# Phase 1 — Ideation

## Problem Statement
Manual IT laptop procurement can cause delays, inconsistent specifications, repeated data entry and poor visibility into fulfillment.

## Proposed Solution
Build a ServiceNow self-service catalog workflow that captures laptop requirements and automatically generates a fulfillment task after approval.

## Expected Benefits
- Faster request processing
- Consistent hardware specifications
- Reduced manual intervention
- Better auditability
- Clear ownership of fulfillment tasks
