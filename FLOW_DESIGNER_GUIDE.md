# Flow Designer Guide

1. Open **Service Catalog** and create the Standard Laptop catalog item.
2. Add required variables.
3. Configure the approval mechanism.
4. Open **Flow Designer**.
5. Create a flow for the requested item.
6. Configure the approval condition.
7. Add an action to update the RITM.
8. Add an action to create a Catalog Task.
9. Populate task fields from the request.
10. Set the assignment group to Hardware.
11. Test with an approved request.
12. Capture screenshots for `live_execution_proofs/`.
