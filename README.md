Streamlining IT Procurement: Automating Standard Laptop Orders with Flow Designer

Team ID: SWTID-2026-9755
Team Size: 5
Team Leader: Mohammed Ashif

Project Overview

This project documents a ServiceNow workflow for standard laptop procurement. Employees submit laptop requests through Service Catalog. After approval, Flow Designer updates the requested item and creates a fulfillment Catalog Task for the Hardware team.

Objectives

- Provide a self-service laptop request catalog item.
- Standardize laptop specifications.
- Route requests for approval.
- Automatically create fulfillment tasks after approval.
- Improve request tracking and accountability.

Workflow

Employee → Service Catalog → Laptop Request → Approval → Flow Designer → Catalog Task → Hardware Fulfillment
