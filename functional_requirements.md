# Functional Requirements

| ID | Requirement |
|---|---|
| FR01 | User can request a standard laptop |
| FR02 | User can select laptop model |
| FR03 | User can select RAM |
| FR04 | User can select storage |
| FR05 | User must provide business justification |
| FR06 | Request requires approval |
| FR07 | Approved request triggers automation |
| FR08 | Automation creates a Catalog Task |
| FR09 | Task is assigned to Hardware |
| FR10 | Request status remains traceable from REQ to RITM to TASK |
